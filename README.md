# Blind Sector Legal

Политика конфиденциальности и сторонние лицензии для **Blind Sector** (`com.goethe47.blindsector`), статический сайт для ссылки из Google Play Console и из самой игры.

## Публикация

Включите GitHub Pages: **Settings → Pages → Source: ветка `main`, папка `/` (root)**. Через минуту-две страницы поднимутся:

```
https://goethe47.github.io/Blind-Sector-LegaL/              — политика конфиденциальности
https://goethe47.github.io/Blind-Sector-LegaL/licenses.html — сторонние лицензии
```

Первый адрес идёт в поле Privacy Policy в Play Console.

Эти же адреса зашиты в игре в `AdsConfig` (`PrivacyPolicyUrl`, `LicensesUrl`) в файле `Assets/Scripts/BlindSectorAds.cs`. Регистр в имени репозитория имеет значение — если репозиторий переименуют или сайт переедет на свой домен, поправить константы там.

## Состав

- `index.html` — политика конфиденциальности
- `licenses.html` — сторонние лицензии на звук, шрифты и SDK
- `roadmap.html` — дорожная карта для тестеров, единственная страница на русском
- `styles.css` — оформление в палитре игры
- `fonts/` — Rubik и Unbounded, те же, что в игре, плюс тексты лицензий OFL
- `.nojekyll` — отключает обработку Jekyll на GitHub Pages

Сайт только на английском: это язык по умолчанию и в игре, и в карточке Play.

Шрифты лежат локально намеренно: страница про приватность не должна заставлять браузер читателя ходить на чужой шрифтовый сервер.

## Что перепроверять

1. **Дата обновления** на обеих страницах — при любом изменении рекламной конфигурации или состава сторонних материалов.
2. **Acquire Optimization** в панели монетизации Unity — от неё зависит значение «время использования приложения» в декларации Data safety.
3. **Состав рекламных сетей** — добавление любой новой сети требует правки политики и декларации Data safety до выпуска.
